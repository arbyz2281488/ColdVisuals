# Visuals — cosmetic Fabric mod (Minecraft 1.21.4, Java Edition)

The jar is built automatically by GitHub (see .github/workflows/build.yml).

Controls: Right Shift = GUI, C = zoom.
GUI: LMB = toggle module, RMB = settings, drag sliders.
Config: .minecraft/config/visuals.properties

Install: Fabric Loader 1.21.4 + Fabric API + the built jar in .minecraft/mods
